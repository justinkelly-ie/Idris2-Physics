# ⚡ Idris2-Physics3

**Discrete Dirac Spinors, Poynting Vectors & Particle Kinematics for Idris 2**

`Idris2-Physics3` implements physical field laws on discrete state space:
- **Discrete Dirac Spinors**: Relativistic fermion currents and Pauli exclusion.
- **Poynting Energy Theorem**: Electromagnetic energy flux conservation.
- **2-to-2 Particle Kinematics**: Scattering amplitudes and discrete momentum conservation.

---

## 🚀 Building & Installing

Built with Idris 2 (`0.8.0`):

```bash
idris2 --build Idris2-Physics3.ipkg
idris2 --install Idris2-Physics3.ipkg
```
